## 0. 问题定位：为什么抗炎只能做到「最佳状态」而不是「READY」

抗炎方向有三个现成模型，但团队的决定性三组检验（A=抗炎肽 / B=随机蛋白碎片 / C=不抗炎的其他功能肽）把它们的问题钉死了：

| 模型 | C vs A（该≈0.5，分得清抗炎与其他功能） | C vs B（该>0.5，分得清功能肽与碎片） | 判决 |
|---|---|---|---|
| AIP-iFeature-LightGBM（v5） | **0.423**（比随机还差，主动把 C 排在 A 之上） | 0.886（强） | 只学会「功能肽 vs 碎片」 |
| AIP-ESM2（v8） | **0.546**（贴随机） | 0.830（强） | 同上，换特征也救不了 |
| iMFP-LG（AIP 通道） | 0.994（但**训练集与测试集 100% 重叠**，是记忆泄漏） | 0.107（碎片反而高分） | 泄漏 + 碎片盲点 |

共同缺陷一句话：**它们测的是「这条肽像不像一个功能肽」，不是「这条肽抗不抗炎」**。根因是训练基准 IF-AIP 的负例 79.7% 是随机滑窗碎片（且多为固定 15-mer），模型只要学会「短而像功能肽 vs 长而像碎片」就能在基准上拿高分，从未被要求区分「抗炎」与「其他功能」。

但——**能榨出的信号是真实存在的**：ESM-2 嵌入在干净独立数据上抗炎 AUC 达 0.802 / 0.903（AIP-ESM2 wiki），说明表示底座携带真实抗炎信号，只是被错误负例拖垮。所以本管线的策略是：**换掉「训练」这条路，在「选取」这条路上用三重对策抵消缺陷。**

## 2. 第一道硬约束：长度有效性窗口（最关键，先剔无效区）

团队的 OOD 实测给出一条硬边界：AIP 模型训练集最短 11 aa（`min_len=11`，无 ≤10 aa 样本）；在 ≤10 aa 的外部短肽集上，ESM2+Classical 的 **AUC = 0.498（随机，CI 0.398–0.588）**、MCC ≈ −0.01。也就是说 **≤10 aa 的分数是随机噪声，绝不能当活性证据**。

因此抗炎选取的**硬前提是长度 ∈ [11, 30] aa**（本项目 95% 的肽本来就在 20–30 aa，损失极小）。这一刀同时切掉了两个隐患：短肽的「长度捷径」（越短越像功能肽）和「无效外推」。

**PostgreSQL（硬约束 + 安全门控，可空缺）**：

```sql
-- 硬约束：长度有效性窗口 [11,30] + 安全门控（可空缺）
SELECT
  id, sequence, length, source,
  aip_v5, aip_esm2, imfp_lg_aip,
  imfp_lg_acp, imfp_lg_adp, imfp_lg_ahp, imfp_lg_amp,
  aopxsvm, amplify, blsam_tip_lr, blsam_tip_gbm,
  plm4cpps, algpred2, bepipred,
  toxinpred3, hemopi2, mhcflurry, netmhcipan_pctrank,
  CASE WHEN hemopi2 IS NOT NULL AND hemopi2 >= 0.50 THEN 'HEMO' END AS flag_hemo,
  CASE WHEN mhcflurry IS NOT NULL AND mhcflurry >= 0.87 THEN 'MHC_I_SB' END AS flag_mhci,
  CASE WHEN netmhcipan_pctrank IS NOT NULL AND netmhcipan_pctrank <= 2 THEN 'MHC_II_SB' END AS flag_mhcii,
  (hemopi2 IS NOT NULL) AS assessed_hemo,
  (mhcflurry IS NOT NULL) AS assessed_mhci
FROM igem_peptides
WHERE length BETWEEN 11 AND 30                        -- 有效性窗口（硬）
  AND (toxinpred3 IS NULL OR toxinpred3 < 0.38)       -- 毒性硬门控
  AND (hemopi2    IS NULL OR hemopi2    < 0.50);      -- 溶血：present-and-failing
-- 注：L0 理化过滤（GRAVY ∈ [-2.0,2.5]、净电荷 ∈ [-3,6]）可在 SQL 或 Python 里叠加，
--     用于剔除明显不成药的多肽，是团队 screen_pipeline.py 里已验证可用的规则层。
```

## 3. 第二道对策：L1→L2 级联（工程可行性）

团队已实测两级吞吐：**L1（经典 iFeature 特征，LightGBM）≈ 19.1 万条/秒**，**L2（ESM2+经典）≈ 2,010 条/秒**（10 核 CPU）。20M 全量走 L2 约需 2.8 小时，而「L1 全量 → 只对 L1 头部走 L2」可大幅加速且真阳召回损失很小（`cascade_sim.py` / `cascade_sim.json` 已量化各保留比例的召回）。

本方向用同一级联：`aip_v5`（L1）先全量粗筛出「像功能肽」的头部（如 top 20%），只对这部分跑/取用 `aip_esm2`（L2）——**这既省算力，也顺带做了第一层漏斗**。若 `aip_esm2` 已全量预计算，则级联退化为「用 L1 排名做候选池、用 L2 排名做精排」，逻辑不变。

## 4. 第三道对策：双重去混淆（长度捷径 + 跨功能）

这是本方向「最佳状态」的核心。AIP 分数有两个已知污染，逐个扣掉：

**4.1 去长度捷径**：AIP 分数与长度 Spearman ρ 高达 +0.53（训练负例 79.7% 为固定 15-mer）。做法是**按长度分桶各取 Top-K**（分层），而不是全局取 Top-K——否则高分段会被某一长度垄断。桶划分沿用团队实测：`(11–15) (16–20) (21–25) (26–30)`。

**4.2 去跨功能混淆**：因为模型把「所有功能肽」都打高分，我们把「这条肽在其他功能上的得分」当作『它有多像通用功能肽』，从 AIP 分里**减去**这部分，剩下的才是 **AIP 特有信号（`aip_specific`）**。其他功能分取自：抗氧化（`aopxsvm`）、抗菌（`amplify`）、抗黑素（`blsam_tip_lr`）、以及 iMFP-LG 的其余四通道（`imfp_lg_acp/adp/ahp/amp`）——这就是「用手里所有工具」的具体落法。

**Python（pandas）：级联候选池 + 集成 + 双重去混淆**：

```python
import pandas as pd, numpy as np

df = pd.read_sql(query_above, conn)        # §2 的 SQL 结果（已过有效性窗口 + 安全门控）

# ---------- 3. L1→L2 级联：用 L1(v5) 取候选头部 ----------
KEEP_FRAC = 0.20
df = df[df['aip_v5'].notna()].copy()
df['l1_rank'] = df['aip_v5'].rank(pct=True, ascending=True)
df = df[df['l1_rank'] >= 1 - KEEP_FRAC]    # 只保留 L1 头部 20%

# ---------- 4.1 去长度捷径：按长度分桶（分层 Top-K 用） ----------
def bucket(L):
    for lo, hi in [(11,15),(16,20),(21,25),(26,30)]:
        if lo <= L <= hi: return f"{lo}-{hi}"
    return None
df['len_bucket'] = df['length'].map(bucket)

# ---------- 4. 三模型集成（ESM2 主、v5 辅、iMFP-LG 次） ----------
# 权重依据：ESM2 独立数据 AUC 0.80–0.90（最干净）> v5（功能肽 vs 碎片最强）> iMFP-LG（有泄漏）
df['aip_ens'] = (0.55 * df['aip_esm2'].fillna(df['aip_v5'])
               + 0.30 * df['aip_v5'].fillna(0)
               + 0.15 * df['imfp_lg_aip'].fillna(0))

# ---------- 4.2 去跨功能混淆：aip_specific = AIP 分位 − 最强其他功能分位 ----------
other = pd.DataFrame({
    'antiox':   df['aopxsvm'].rank(pct=True),
    'antibac':  df['amplify'].rank(pct=True),
    'antimel':  df['blsam_tip_lr'].rank(pct=True),
    'imfp_acp': df['imfp_lg_acp'].rank(pct=True),
    'imfp_adp': df['imfp_lg_adp'].rank(pct=True),
    'imfp_ahp': df['imfp_lg_ahp'].rank(pct=True),
    'imfp_amp': df['imfp_lg_amp'].rank(pct=True),
})
df['other_max'] = other.max(axis=1)        # 该肽被「任一其他功能」最强解释的程度
df['aip_specific'] = df['aip_ens'].rank(pct=True) - df['other_max']
# aip_specific 高 = 该肽像抗炎、且这份『像』无法被其他功能解释 → 更可能是真抗炎信号
```

> 为什么这样能部分纠偏：模型把「功能肽」都打高分，那么「高分且没有任何其他功能模型认领」的肽，才更有可能是抗炎特有的。这是用现有工具能做的、最接近「C vs A 分离」的启发式替代。**必须承认它是启发式，不是经过验证的抗炎判定。**

## 5. 可开发性加权（软，与另三方向同套）

抗炎候选通过功能层后，用 `plm4cpps`（穿膜，越高越好）、`algpred2`（致敏，反向）、`bepipred`（B 细胞表位，反向）、`aggrescan_a3v`（聚集，反向）做排名。权重用**温莎化标准差**（先把各分量的极端值按分位缩尾、再算标准差，用缩尾后的标准差衡量区分度，区分度高的分量自动升权），归一化后乘人工系数 α。代码同抗氧化方向第 3 节。

## 6. 综合分与 Top-K 选取（分层 + 去混淆后排序）

综合分在候选池内排名，且**先分层、后排序**，避免长度捷径：

```python
ALPHA = 1.0
# 分量（0–1，越高越好）
comps = {
    'aip_specific': (df['aip_specific'] - df['aip_specific'].min()) /
                    (df['aip_specific'].max() - df['aip_specific'].min()),
    'cpp':     df['plm4cpps'].rank(pct=True),
    'sens':    1 - df['algpred2'].rank(pct=True),
    'epitope': 1 - df['bepipred'].rank(pct=True),
    'agg':     1 - df['aggrescan_a3v'].rank(pct=True),
}
weights = {k: v.std() for k, v in comps.items()}      # 简化的区分度权重（生产版用温莎化 std）
weights = {k: w / sum(weights.values()) for k, w in weights.items()}
df['composite'] = sum(weights[k] * comps[k] for k in weights) * ALPHA

# 分层 Top-K：每个长度桶各取前 K，合并成 Top 150；Bottom 100 同理取池内最低
per_bucket = 150 // df['len_bucket'].nunique()
top150 = (df.sort_values('composite', ascending=False)
            .groupby('len_bucket', group_keys=False).head(per_bucket))
bottom100 = df.sort_values('composite').head(100)
```

递送调权（外用 / 纳米载体 / 微针 / 注射四套权重乘数）与另三方向一致：外用 CPP↑溶解度↑热稳定↓；纳米溶解度↑CPP↓；微针溶解度↑热稳定↑；注射免疫阈值收紧（带 MHC 标记者判 `failed_safety`、综合分置 0）。

## 8. 升级路径（把 WIP 转 READY 的唯一正路）

本管线是「用现有工具做到的最好」，但要真正 READY，必须**重建基准后重训**，团队其实已经备好素材：

1. **干净负例已就位**：团队已用 BIOPEP-UWM 建好「不抗炎的其他功能肽」池（`biopep_all.json` / `short_benchmark_stats.json`，n_unique_seq 4251，`neg_activity_pool` 含 ACE inhibitor、AChE inhibitor 等），这正是 IF-AIP 缺的那一类负例。
2. **负例配比**：新基准负例须同时含「实验证实无抗炎活性的功能肽」+「随机碎片」两类，让模型被迫学「抗炎 vs 其他功能」，而不是「功能肽 vs 碎片」。
3. **长度平衡**：训练集须覆盖 11–30 aa 全长（当前负例 79.7% 是固定 15-mer，是长度捷径的根源），并做长度分层采样。
4. **重训 + 复检**：用 ESM-2 嵌入（独立 AUC 0.80–0.90 已证明底座可用）重训，再用团队的 `generic_decistest.py` 三组检验复检，目标是把 **C vs A 拉离 0.5**（当前 0.42–0.55）。
