## 1. 安全门控（可空缺性原则，与另两方向一致）

统一规则不变：分数**存在且超过阈值**才淘汰；**NULL 一律放行**并标记未评估。

**PostgreSQL 选取（安全 + 弱功能候选池）**：

```sql
-- 抗黑素方向：安全门控（可空缺）+ BLSAM-TIP 双模型共识候选池
SELECT
  id, sequence, length, source,
  blsam_tip_lr, blsam_tip_gbm,
  toxinpred3, hemopi2, mhcflurry, netmhcipan_pctrank,
  plm4cpps, algpred2, bepipred,
  CASE WHEN hemopi2           IS NOT NULL AND hemopi2           >= 0.50 THEN 'HEMO'     END AS flag_hemo,
  CASE WHEN mhcflurry         IS NOT NULL AND mhcflurry         >= 0.87 THEN 'MHC_I_SB'  END AS flag_mhci,
  CASE WHEN netmhcipan_pctrank IS NOT NULL AND netmhcipan_pctrank <= 2 THEN 'MHC_II_SB' END AS flag_mhcii,
  (hemopi2 IS NOT NULL) AS assessed_hemo,
  (mhcflurry IS NOT NULL) AS assessed_mhci
FROM igem_peptides
WHERE (toxinpred3 IS NULL OR toxinpred3 < 0.38)   -- 毒性硬门控
  AND (hemopi2    IS NULL OR hemopi2    < 0.50)   -- 溶血：present-and-failing
  -- 功能：双模型一致阳性（保守）。仅 GBM 阳性者不进主池，但可单独留作「宽松候选」
  AND blsam_tip_lr  >= 0.50
  AND blsam_tip_gbm >= 0.50;
```

> `tipred` 不进入任何 WHERE——它在 20M 上 99.5% 阳性，当过滤器毫无富集力，已排除。
> 双模型共识（`lr>=0.5 AND gbm>=0.5`）是最保守的候选池；若共识池太小，可在 Python 里放宽到「至少一模型 ≥0.5」但单独打 `loose` 标记，供人工权衡。

## 2. 功能排序：BLSAM-TIP 双模型共识（弱，必须标注未校准）

BLSAM-TIP 本地重建的两模型在真实库上分歧大（一致率 51%），且都未做概率校准——输出只能当**排序分**，不能当「XX% 是抗黑素肽」。处理策略：

- **共识优先**：两模型都 ≥0.5 的肽进主候选池，按两模型平均分降序排。
- **仅 GBM 阳性者单独留档**（`loose` 标记），因其宽松（55% 阳性率）易产假阳性，仅作补充。
- **LR 单模型阳性**参考价值低（学反），不单独成池。

**Python（pandas）通道划分 + 标注**：

```python
import pandas as pd
df = pd.read_sql(query_above, conn)
```
