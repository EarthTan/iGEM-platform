# PeptiCraft 多管线搭建方案（证据驱动版）

> 写于 2026-09-05，基于 `README.md` 项目定位与 18 个工具目录下的 `wiki.md` / 深度评估报告。
> 本文按「第一轮猜想 → 证据证伪 → 第二轮修正 → 成熟方案」的迭代结构组织，便于追溯每一个设计决定背后的数据依据。

## 一、背景与任务目标（先对齐）

PeptiCraft 的搜索空间是约 **20,248,885 条短肽**（长度 1–30 个氨基酸，95% 集中在 20–30 aa），数据来源以宏基因組 `legacy_mgy_2022`（约 1900 万条）为主，辅以 UniRef/UniProt 簇、PDB、SwissProt、专利序列片段。当前阶段是**管线搭建**：目标不是复现第一阶段那条八轮漏斗，而是把能力泛化为可复用的预计算平台——对每个功能方向，从约两千万肽里筛出「安全、功能、可开发性都达标」的顶级候选，最终每个方向产出约 250 个预计算 construct（Top 150 + Bottom 100 对照），整体淘汰率约 99.99%。

四个功能方向就绪度不同（来自 README）：**抗氧化已就绪、抗菌模型待部署、抗炎与抗黑素仍在调研**。这就决定了「多管线」不是四条一模一样的流水线，而是一条**共享的安全门控骨架** + **四条方向特异的功能漏斗** + **按递送方式加权重算的可开发性层**。

## 二、工具全景与就绪度判定（一张表看清谁能进管线）

先给结论：18 个工具里，能作为**硬门控**的只有 3 个安全工具；能作为**功能主排序**的只有 2 个（抗氧化、抗菌）；**抗炎三个工具全部失效**；**抗黑素只有 1 个弱排序候选**；可开发性里只有 **pLM4CPPs 对短肽直接有效**，热稳定/溶解度要放到「构建体级别」才有意义，聚集/溶剂可及性（A3D/SASA）需要三维结构、明确在 MVP 之外。

|---|---|---|---|---|

## 三、第一轮猜想（读文档之前，仅凭 README 的直觉）

读工具文档之前，凭 README 的「八轮漏斗 + 三 veto + 九项评分」我会自然假设以下四点，把它们摆出来是为了和证据对照：

1. **漏斗可以直接照搬**。第一阶段是八轮逐级收紧，第二阶段 MVP 砍掉第五到八轮（三维结构），那前四轮「功能分选 → 安全硬阈 → 深度评分 → 拼 construct」应该平移过来即可。
2. **每个方向挑一个「最佳工具」当硬门控**。比如抗氧化用 AnOxPePred（DTU 出品、被引用广），抗菌用 AMPlify，抗黑素用 TIPred，抗炎用 iMFP-LG；谁分高谁进。
3. **九项评分里的可开发性工具（TemStaPro、SoDoPe、A3D）对短肽直接可用**，因为它们本来就是给序列打分的。
4. **四个方向平行、同等就绪**，只是模型成熟度不同，排期上依次接入即可。

这四个猜想里，**没有一个完全站得住**，下面逐条被证据推翻或修正。

## 四、读文档后的关键证据（逐类证伪与修正）

**4.1 安全门控不能用「单等位基因 + 默认阈值」糊弄。** MHCflurry 单跑 A*02:01 会让 97.25% 肽得分恰好为 0，看上去「都没免疫原性」，但团队已经用 23 个东亚等位基因重算，强结合子识别率提升 4.76×——说明单等位基因口径会系统性漏掉风险。NetMHCIIpan 更反直觉：本库 94.48% 都是弱结合（WB），因为它的序列「比随机天然肽更像一个 MHC-II 结合者」，所以 SB/WB 标签在这里不是稀有信号，**必须用 %Rank（跨等位基因可比的百分等级）当尺度**，不能用 BindLevel。结论：免疫原性门控要建成「MHC-I 多等位基因 best-case + MHC-II %Rank 软风险」的组合，而不是一个 0.5 开关。

**4.2 功能工具几乎没有能当「硬门控」的。** AnOxPePred 第三方测试已近随机（AUC 0.5–0.6）；AOPxSVM 在 20M 上把 72.83% 判阳性，因为它是「真实肽 vs 随机序列」学出来的，不是「抗氧化 vs 非抗氧化」；TIPred 99.5% 阳性彻底失准；三个抗炎工具全军覆没（基准负例构造错误 + 数据泄漏）。唯一干净能用的是 **AMPlify（抗菌）**，但它也只擅长「典型数据库 AMP vs 长链球状蛋白」这一区间。所以功能方向的正确用法是**排序（ranking）+ Top-K 取候选**，绝不能直接拿 0.5 当放行线。

**4.3 可开发性工具大多「训在长蛋白、用在短肽」会退化。** TemStaPro 训练数据最短也在数百 aa，3–30 aa 上输出单峰贴 0.5、没有任何生物信号；SoDoPe 测的是「大肠杆菌里重组表达后是否形成包涵体」，根本不是「游离肽在水里的溶解度」，20M 上的 AUC=1.0 是循环标签假象；A3D 和 SASA 必须吃三维结构，短肽没有。唯一对短肽直接成立的是 **pLM4CPPs（穿膜倾向）**，AUC 0.983、富集 15×，但精确率约 50%，只能当排序特征。这意味着可开发性要拆成三层：肽级有效（pLM4CPPs、一维 AGGRESCAN）、构建体级可用（TemStaPro/SoDoPe 拼到全长融合蛋白上再算）、MVP 范围外（A3D/SASA 三维评估）。

**4.4 四个方向不是「同等就绪」而是「1 就绪、1 待部署、2 调研」。****抗炎三个工具全部不可用**（基准坏 + 泄漏），不能为了凑四个方向强行上线；**抗黑素只有 BLSAM-TIP 本地重建版能当弱排序**，且未校准、需湿实验闭环。这和 README 的就绪度判断一致，但给了更硬的理由：抗炎方向的阻塞点是「没有干净的训练基准」，不是「没有模型」——负例必须同时含「实验证实无抗炎活性的功能肽」和「随机碎片」两类，重训之后才可能有可用筛选器。

## 五、第二轮修正猜想（证据进来之后）

把上面的证伪收拢，修正后的骨架是：

1. **漏斗不复用第一阶段形态**，而是「共享安全骨架 → 方向特异功能漏斗 → 递送加权可开发性 → 构建体组装」四段式。
2. **安全门控 = 3 硬否决 + 2–3 软信号**：硬否决是 ToxinPred3(<0.38)、HemoPI2(<0.5)、MHCflurry 多等位基因非强结合；软信号是 NetMHCIIpan %Rank 风险、AlgPred2 致敏、BepiPred 连续分——软信号进入综合分或人工复核，不当场淘汰。
3. **功能层全部用排序 + 分位 Top-K**，不用 0.5 阈值；方向就绪度决定是否能产出预计算 construct。
4. **可开发性分层处理**，pLM4CPPs 进肽级评分，热稳定/溶解度放到构建体级，聚集用一维 AGGRESCAN 兜底，三维评估整体出 MVP。

## 六、成熟的多管线搭建方案

### 6.1 总体架构：一条骨架 + 四条漏斗 + 一层加权

```
[Stage 0] 特征预计算（一次跑全库，存分）
     │  对 20M 肽跑：ToxinPred3 / HemoPI2 / MHCflurry(23 allele) / NetMHCIIpan(131 allele)
     │              / AnOxPePred / AOPxSVM / AMPlify / pLM4CPPs / BepiPred / AlgPred2
     │              / BLSAM-TIP（抗黑素弱排序，待校准）
     ▼
[Stage 1] 共享安全骨架（硬否决 AND 组合，任一不过即淘汰）
     │  ToxinPred3<0.38  AND  HemoPI2<0.5  AND  MHCflurry 多allele 非强结合
     ▼
[Stage 2] 方向特异功能漏斗（排序，非硬门控）
     │  抗氧化: AOPxSVM 分位Top-K + AnOxPePred 保守确认
     │  抗菌  : AMPlify ≥0.5, Top-K
     │  抗炎  : 【阻断，WIP，等基准重建】
     │  抗黑素: BLSAM-TIP 双模型共识（弱排序，human_review_pending）
     ▼
[Stage 3] 可开发性加权（肽级 + 构建体级，递送方式决定权重）
     │  pLM4CPPs(CPP) / AlgPred2(致敏·软) / BepiPred(表位·软) / 一维AGGRESCAN(聚集·软)
     │  + 递送方式调整 CPP/溶解度/热稳定 权重与免疫阈值
     ▼
[Stage 4] 构建体组装 + 递送调后分（Top150 + Bottom100/方向）
     │  拼 backbone+linker+peptide → 对全长融合蛋白补 TemStaPro/SoDoPe(构建体级,  advisory)
     │  → 算九项基线分 + 四种递送调后分 → 安全状态 passed/failed_safety
     ▼
[Stage 5] 落库 + API（对齐 README 后端指引的字段与接口）
```

### 6.2 共享安全骨架（硬否决 + 软信号，含阈值表）

硬否决三者是「与」关系——**任一不过即整条肽淘汰，综合分只对 passed 算**（对齐 README「一票否决」铁律）。软信号不淘汰，但进综合分或触发人工复核。

| 门控 | 工具 | 通过条件 | 注射递送的收紧 | 数据依据 |
|---|---|---|---|---|
| 毒性（硬） | ToxinPred3 | score < 0.38 | 不变 | 默认阈值；<15 aa、PDB 来源判毒率偏高，结果页需标注来源/长度偏置 |
| 溶血（硬） | HemoPI2 | score < 0.5（建议，README 写 0.55） | 不变 | 中位数 0.518 贴阈值，灰区 0.4–0.6 用交叉验证；建议压到 0.5 覆盖两类模型判别区 |
| MHC-I 免疫（硬） | MHCflurry（23 allele best） | 任一东亚 allele 上均非强结合（IC50≥50 nM） | 收紧为「非强结合且非弱结合（IC50≥500 nM）」≈ README 的 0.35 口径 | 单 A*02:01 低估 4.76×；consensus≥3 allele 的 2.70% 肽直接优先排除 |
| MHC-II 免疫（软） | NetMHCIIpan（%Rank） | 不作为硬淘汰；%Rank 进风险分 | 收紧 %Rank 阈值（如 SB 数≥k 即风险） | 本库 favorable 偏置，BindLevel 失效，%Rank 才是稳定尺度 |
| 致敏（软） | AlgPred2 | <0.5 为安全，≥0.5 进关注池 | 收紧到 <0.4 | 特异性仅 6.1%，只能软；≤7 aa 短肽单独复核 |
| B 细胞表位（软） | BepiPred-3.0 | 连续 score 低分优先，不二值判 | 同左 | 短肽 88% 溢出，仅用连续分做相对排序 |

> 说明「%Rank」：NetMHCIIpan 把每条肽的预测得分和一组随机天然肽背景对比，排在前 2% 叫强结合（SB）、前 10% 叫弱结合（WB）。它是跨等位基因可比的百分等级，所以即便本库整体「像结合者」，%Rank 仍能稳定排序——这正是它比原始 IC50 更适合做大规模库风险尺度的原因。

### 6.3 各功能方向漏斗（就绪度决定是否能产出 construct）

**方向一 · 抗氧化（READY，可产 250 construct）**
主排序用 **AOPxSVM**，但**绝不用 0.5 阈值**（会保留 72.83%）。改用全库分位 Top-K：先算全库分位（P50/P90/P99），取 ≥P90（约前 10%）作候选池。再用 **AnOxPePred FRS** 做保守确认——它第三方测试虽近随机，但高特异度意味着「FRS≥0.5 且同时通过 AOPxSVM 高分段」的候选假阳性低，值得优先进湿实验。综合功能分 = AOPxSVM 分位与 AnOxPePred FRS 分位的秩平均（rank-average），再取 Top 150 + Bottom 100 对照。

**方向二 · 抗菌（READY，模型待部署）**
直接用 **AMPlify 原版 v0.1.0**（已跑通、即开即用）输出 AMP 概率，阈值 0.5 取 Top-K。需注意它的偏见：偏袒「阳离子两亲性短肽（尤其蛙类来源）」。若候选要覆盖更广化学类型，可并行 AMPlify-ESM2（平衡版，排序更稳）做交叉验证，但部署成本（6.5 亿参数、约 39.5 GB 权重）高，MVP 先上原版。

**方向三 · 抗炎（WIP，阻断上线）**
三个工具均不可用（v5 与 ESM-2 都只学会「功能肽 vs 碎片」、分不清抗炎；iMFP-LG AIP 通道数据泄漏）。**本方向暂不产出预计算 construct**，界面标 WIP。真正的待办是重建基准：负例必须同时含「实验证实无抗炎活性的功能肽」与「随机蛋白碎片」两类，再用 ESM-2 嵌入重训（独立数据上 ESM-2 抗炎 AUC 已达 0.80–0.90，证明表示底座可行）。这是「干湿闭环」的核心交付之一。

**方向四 · 抗黑素（WIP，弱排序候选）**
TIPred 排除出管线。保留 **BLSAM-TIP 本地重建版（LR + LightGBM 双模型）** 作为弱排序：取两模型一致为阳性者优先，仅 GBM 阳性者保持警惕；输出必须标注「未校准、排序分非概率」与 `human_review_pending`。在湿实验校准（Platt/等渗回归）之前，不把它当硬门控，产出的 construct 标 WIP。

### 6.4 可开发性评分（分层，递送方式决定权重）

肽级直接有效：
- **pLM4CPPs（CPP 穿膜倾向）**：连续分进评分，外用/纳米载体/微针递送时权重调高，注射时权重调低。
- **一维 AGGRESCAN（a3v 标度）**：规则法、按氨基酸固有聚集倾向给肽级软特征，代替需要三维结构的 A3D。
- **AlgPred2（致敏）、BepiPred（表位）**：软安全信号，越低越好。

需放到构建体级（Stage 4 拼好全长融合蛋白后再算，结果标 advisory）：
- **TemStaPro（热稳定）**：对 3–30 aa 退化，但对丝素/胶原等数百 aa 骨架 + linker + 肽的融合蛋白可用，作为保守的稳定性参考。
- **SoDoPe（溶解度）**：语义是「大肠杆菌重组表达可溶性」，对全长融合蛋白（我们要表达的就是融合蛋白）有意义，可作为表达可溶性的初筛；对游离短肽无效。

MVP 范围外（明确不做）：A3D/SASA 三维评估、基于结构的帕累托筛选、Agent 自主触发计算。

### 6.5 综合分与递送加权（数据驱动，不写死）

综合分遵循 README 三条硬约束：**安全一票否决、每个指标只用一次、权重由数据决定**。权重用各指标分数的 **Winsorized 标准差**（温莎化标准差：先把极端值按分位「缩尾」再算标准差，避免少数离群肽扭曲权重）反推——区分度高的指标自动升权、低的降权，仅保留一个人工干预系数 α（默认 1.0）。

递送方式在 Stage 3 改变权重与阈值（对齐 README 前端四套规则，后端必须忠实复现）：
- **外用涂抹**：CPP 权重↑、溶解度权重↑、热稳定权重↓、免疫原性阈值正常（0.50）。
- **纳米载体**：溶解度权重↑、CPP 权重↓、热稳定权重中等。
- **微针**：溶解度权重↑、热稳定权重↑。
- **注射**：免疫原性阈值收紧到 0.35，整体安全权重↑（进入体内后免疫暴露是首要风险）。

### 6.6 构建体组装与预计算产出

每个方向对通过安全 + 功能 Top-K 的肽，枚举 backbone（场景自动匹配或自选）+ 32-linker 组合，产约 250 个 construct（Top 150 + Bottom 100 对照）。每条 construct 必须带：完整序列与分段、九项基线评分、四种递送各自调后分、通道、安全状态（passed / failed_safety，失败者综合分置 0 不参与排名）、肽段来源说明。落库字段对齐 README 后端指引的 `Construct / BackboneProtein / Linker / DeliveryMethod / FunctionDirection` 等对象。

## 七、风险与待办（决定方案能否从「设计」走到「跑通」）

1. **抗炎方向阻塞点是基准，不是模型**：必须新建含「干净负例」的抗炎基准并重训，否则该方向永远 WIP。这是最高优先级的干湿闭环任务。
2. **抗黑素弱排序待校准**：BLSAM-TIP 未做概率校准、LR 学反（Cys 主导、Tyr/Arg 被排除），需湿实验标签做 Platt/等渗回归，在此之前只能 human_review_pending。
3. **安全门控的阈值需湿实验回标**：ToxinPred3 的 0.38、HemoPI2 的 0.5、MHCflurry 注射 0.35 目前都是「工具默认 / README 规定」，应在已知标签的小批量验证集上实测 precision/recall 后回头校准（对齐各 wiki 的「阈值校准待办」）。
4. **可开发性在肽级有真空**：短肽的热稳定/溶解度目前没有可靠的肽级工具（TemStaPro/SoDoPe 都需长序列），要么走 ESM-therm 路线，要么接受「只在构建体级评估」的妥协——这是方案里明确留出的工程缺口。
5. **多等位基因 MHCflurry 已重算、NetMHCIIpan 131 allele 已跑**，这两块工程账已结清，后端直接消费结果表即可，不必重跑。

> 一句话收尾：本方案把「18 个工具」按证据重新分层——**3 个硬安全门控 + 2 个可用功能主排序（抗氧/抗菌）+ 1 个弱排序（抗黑素）+ 若干软信号**，抗炎方向因基准损坏而主动阻断；可开发性拆成肽级/构建体级/出 MVP 三层；最后用 Winsorized 标准差权重 + 递送调权把各分数合成每条 construct 的综合分。这既满足 README 的「安全一票否决、指标只用一次、权重数据驱动」三条铁律，也诚实标出了每一处「未验证 / 待校准」的坑。
