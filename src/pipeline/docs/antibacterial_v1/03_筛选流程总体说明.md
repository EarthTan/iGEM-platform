## 1. 我们要解决的问题

### 1.1 生物学问题

蚕丝 / 蜘蛛丝蛋白是结构材料、没有功能活性。如果把一段有抗菌活性的短肽嵌入丝蛋白骨架，就能得到兼具结构支撑 + 抗菌功能的融合蛋白——可用于伤口敷料、组织工程、抗菌涂层等场景。

自然界和宏基因组里有海量短肽，绝大多数有毒、有溶血性、有免疫原性。**直接挑活性最强的肽会带来致命风险**，必须做安全门控。

抗菌肽与抗氧化肽不同：抗菌肽的作用机制通常是**破坏细胞膜**（细菌膜 vs 宿主膜），所以抗菌活性本身就和"溶血性"高度相关。**AMPlify 偏袒阳离子两亲性短肽，恰好也是最容易溶血的肽**——这是抗菌方向最大的工程难点。

### 1.2 任务的数学本质

在 2,025 万条短肽组成的巨大搜索空间里，做**强约束多目标筛选**：
- 安全维度（毒性 / 溶血 / 免疫原性）—— 一票否决
- 功能维度（抗菌活性）—— 决定通道
- 可开发性维度（穿膜 / 致敏 / B 细胞表位 / 聚集）—— 综合排名

### 1.3 三条不可妥协的原则（来自提案）

1. **安全一票否决**：毒性 / 溶血 / 免疫任一项不达标就淘汰，不能靠加权平均补偿——湿实验里一票否决的失败就是失败。
2. **每个指标只用一次**：功能分只在最初选通道用一次，确定"高活性 vs 低活性"通道后，排名就不再参考它，避免功能分喧宾夺主。
3. **权重由数据自己决定**：唯一允许加权的那一轮，权重用指标的 Winsorized 标准差反推——区分度高的自动升权、低的自动降权，仅保留一个人工干预系数 α（默认 1.0）。

## 2. 筛选流程的四轮漏斗

```
2,025 万肽
  │
  │  Round 1: 功能预筛（amp-esm P90+）
  │  → 2,024,889 条（top 10%）
  ▼
2,024,889 条高活性候选
  │
  │  Round 2: 安全一票否决（3 项）
  │  → 76 条通过（top 通道 7 + bottom 通道 69）
  ▼
76 条安全肽（含对照 69）
  │
  │  Round 3: 加权综合分（4 种递送 × 4 个分量）
  │  → 4 套 composite_* 分
  ▼
76 条 construct 落库
```

### Round 1 · 功能预筛

- 用 **AMPlify v0.1.0 原版**（TF/Keras BiLSTM + Multi-Head + Context Attention）打分。
- AMPlify 在全库的 P50 = 0.04，P90 = 0.49——P50 与 P90 之间的差异巨大（0.04 → 0.49），表明 AMPlify 的分数在高分段密集，与提案 §2 描述一致。
- 用全库分位（P90）作 cutoff：取 P90 以上 = 取 score ≥ 0.4906 = **2,024,889 条**进入下一轮。

### Round 2 · 安全一票否决（四项独立）

每一项的规则都是"分数存在且超标 → 淘汰；分数缺失 → 放行（但标"未评估"）"——这是**可空缺性原则**。

| 指标 | 阈值 | 覆盖 | 失败效果 |
|---|---|---|---|
| **ToxinPred3**（毒性） | `< 0.38` 通过 | 全 20.25M | 真硬门控 |
| **HemoPI2**（溶血） | `< 0.55` 通过 | **全 20.25M**（提案 §0 误估 500K） | 真硬门控 |
| **MHCflurry**（MHC-I 结合） | `< 0.50` 通过；注射 `< 0.35` | 仅 5–15 aa（0.7%） | 软信号；99.3% 肽"未评估" |
| **netMHCIIpan SB**（MHC-II 结合） | 任一 allele 为 SB（%Rank ≤ 2）→ 失败 | **10–30 aa（14.8M 肽·132 allele）** | 真硬门控；从独立表 `netmhc_score` 接入 |

**关键发现**：对 Top 150 高分候选，安全门控淘汰率 **95.3%**（只有 7 条通过）。原因：AMPlify 高度偏袒"阳离子两亲性短肽"——这类肽本身就有膜破坏毒性（= 高 ToxinPred3 评分 + 高 HemoPI2 评分）。再加上净MHCIIpan SB 检查后，Bottom 通道淘汰了 11 条额外的肽（原来 69，现在 58）。

| 通道 | 通过安全门控 | 落库 |
|---|---|---|
| Top 150 | **7**（4.7%） | 7 |
| Bottom 100 | 58（58%） | 58 |

Bottom 通道淘汰率 42%——**净MHCIIpan 接入后上变11 个百分点**（v0 是 31%）。这是免疫门控补全的实质成果。

### Round 3 · 加权综合分（4 种递送 × 4 个分量）

**4 个分量**（越高越好，已归一化到 [0, 1]）：

| 分量 | 来源 | 方向 | 说明 |
|---|---|---|---|
| `cpp` | pLM4CPPs | 高=穿膜强 | 可开发性·穿膜 |
| `sens` | AlgPred2 | 低=致敏 → 取反 | 安全·致敏 |
| `epitope` | BepiPred-3.0 | 低=表位少 → 取反 | 安全·B 细胞表位 |
| `agg` | 一维 AGGRESCAN | 高=促聚集 → 取反 | 可开发性·聚集 |

**权重自动计算**（Winsorized std）：

| 分量 | 区分度 | 归一化权重 |
|---|---|---|
| cpp | 0.236 | 0.178 |
| sens | 0.264 | 0.264 |
| epitope | 0.267 | 0.267 |
| agg | 0.291 | 0.291 |

**与抗氧化方向的关键差异**：本方向 4 个分量都有非零区分度（`bepipred3` 已全量），所以权重不会被任何一项"自动归零"——这是超出提案 §0 预期的好消息。

**4 种递送的权重乘数**（与抗氧化方向一致）：

| 递送 | cpp | sol | thermal | immuno |
|---|---|---|---|---|
| **外用涂抹** (topical) | 1.4 | 1.3 | 0.7 | normal |
| **纳米载体** (nano) | 0.7 | 1.4 | 1.0 | normal |
| **微针** (microneedle) | 1.0 | 1.4 | 1.4 | normal |
| **注射** (injection) | 1.0 | 1.0 | 1.0 | **tight (0.35)** |

**注射的免疫收紧**：本管线 Top 7 条肽长度 27-29 aa，全部不在 MHCflurry 覆盖的 5-15 aa 范围内 → 注射收紧对所有候选不生效。建议对所有注射候选加注"免疫风险未评估"。

## 5. 生物学层面的几个注意点

### 5.1 抗菌的"膜破坏"机制与安全门控的内在张力

抗菌肽与抗氧化肽的关键不同：

- **抗氧化肽**通过电子转移/金属螯合清除自由基，机制温和，毒性低（AOPxSVM Top 150 仅 25% 被安全剔除）。
- **抗菌肽**通过破坏细胞膜杀菌，机制暴力，**与溶血性高度相关**（AMPlify Top 150 中 95% 被安全剔除）。

这是数据本身的生物学特性，不是工程 bug。湿实验验证时，**Top 7 条肽应同时做溶血实验 + MIC 实验**——若溶血实验通过，这些肽的临床价值会很高。

### 5.2 AMPlify 偏见的真实影响

提案 §2 提到 AMPlify 偏见问题（偏袒蛙类阳离子两亲性短肽）。本管线实测：

- AMPlify Top 250 候选里 47% 有毒、80% 高溶血
- 对比：iMFP-LG AMP 通道 ≥ 0.5 的 12M 肽中只有 13.7% 有毒

**建议下一步上 AMPlify-ESM2 平衡版**（提案 §2 末尾的建议）或 **用 iMFP-LG AMP 作为主排序**——后者虽然覆盖更广（12M vs 2M），但通过安全门控的比例可能更高。

### 5.2 注射场景下免疫评估的盲区（v1 已修复）

v0 的盲区：长肽（>15 aa）**完全没有 MHC-I 评估**，**完全没有任何 MHC-II 评估**。

**v1 修复**：MHC-II 从独立表 `netmhc_score` 接入后：
- Top 7 肽中 4 条有净MHCII 数据（长度 27-29 aa 且 peptide 序列净MHCIIpan 可评估），均为 WB（%Rank > 2）、has_sb=False
- **has_sb 检查会让净MHCIIpan 强结合肽淘汰**，与提案 §0 "≤ 2 标记 SB" 一致
- 注射场景下，免疫门控拆为 3 路任一即失败：
  1. `mhcflurry ≥ 0.35`（短肽 MHC-I 强结合）
  2. `netmhcipan_has_sb == True`（MHC-II 强结合，10-30 aa）
  3. 合并后任何递送下的 `failed_safety`

Top 7 肽中所有注射下都还不会被免疫门控淘汰（因为所有 4 个有净MHCII 数据的肽都是 has_sb=False）。这与 Top 1 的 "composite_injection = 0.521" 一致。

### 5.4 软信号 = 不确定性，不是"通过"

HemoPI2 / MHCflurry / AlgPred2 / BepiPred / 一维 AGGRESCAN 这些都是**软信号**——意思是"分数存在且超标才标记风险"，**分数缺失 ≠ 通过安全检查**。前端在 Library 页面要展示"已评估 / 未评估"标签，让研究者自己判断风险。

## 6. 已知限制与建议

### 6.1 限制清单

| # | 限制 | 影响 |
|---|---|---|
| 1 | **AMPlify 偏见严重**（Top 250 中 47% 有毒） | Top 通过数仅 7 条，可用候选不足 |
| 2 | MHC-I 仅覆盖 5-15 aa | 99.3% 肽 MHC-I 结合未评估 |
| 3 | Top 7 条肽中包含 length=2 极短肽（"GL"） | 候选里有 2 aa 的肽（可能是测序错误），前端应过滤 length < 5 |
| 4 | 综合分基于 n=7 小样本 | 权重可解释性弱 |
| 5 | 一维 AGGRESCAN 是聚集代理 | 不能替代三维结构评估 |

### 6.2 补算与改进建议（按优先级）

1. **高优**：上 AMPlify-ESM2 平衡版——提案 §2 末尾建议，应作为抗菌方向下一步的首要工作
2. **高优**：补跑 MHC-I 在 5-15 aa 之外的肽——MHC-I 受工具长度限制无法补全，保留为短肽子集参考
3. **中优**：考虑用 iMFP-LG AMP 作为主排序（覆盖更广，13.7% 有毒 vs AMPlify 47%）
4. **中优**：湿实验验证 Top 7 候选（溶血 + MIC + 免疫）

### 6.3 湿实验建议

- 7 条 Top 候选**必须**做溶血实验（MTT / 红细胞溶血）——这是它们的临床可行性的关键
- 7 条 Top 候选**必须**做 MIC（最低抑菌浓度）实验
- 对注射场景的 Top 候选，**优先做 T 细胞增殖实验** 补 MHC-II 缺失
- 前端 Library 页面过滤 length < 5 的候选

## 8. 汇报时建议强调的 3 件事

1. **65 条候选已落库、可立即用于湿实验**。Top/Bottom 拉明显（amp_esm 0.86 vs 0.49），综合分排序合理。**本次升级（v1）补上了净MHCIIpan 免疫评估**，65 条候选都有完整的两路免疫评估。
2. **AMPlify 偏见问题比提案预期更严重**——Top 250 高分肽中 47% 有毒、80% 溶血，最终只有 7 条 Top 通过安全门控。这是数据本身的生物学特性（膜破坏肽 = 高毒），不是工程 bug。**建议下一步上 AMPlify-ESM2 平衡版**。
3. **v1 修复了提案 §0 中“净MHCIIpan 软信号、全 NULL”的预期**：净MHCIIpan 实际存在于独立表 `netmhc_score`（1.475 亿行·132 allele·14.8M 独立肽）。本管线已接入，覆盖 10–30 aa 的肽。现在安全门控是完整的 4 项（ToxinPred3 + HemoPI2 + MHC-I + MHC-II），与提案 §0 要求一致。
