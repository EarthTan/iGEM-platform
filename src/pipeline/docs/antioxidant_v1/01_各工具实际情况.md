### 2.1 与提案一致（7 项）

**安全硬门控三件套**（提案要求全覆盖）：

- **ToxinPred3**：20.25M 全覆盖。**这是 proposal 中唯一可作硬门控的毒性分数**，其它两个（hemopi2 / mhcflurry）覆盖率不够，硬门控会清空库。
- **AlgPred2**：20.25M 全覆盖。致敏性软信号。
- **pLM4CPPs**：20.25M 全覆盖。穿膜倾向软信号。

**功能主排序**：

- **AOPxSVM**：20.25M 全覆盖。P90 = 0.99584。72.83% 阳性（0.5 阈值失真），必须按全库分位而不是固定 0.5 取阈值。

**覆盖率低的软信号**：

- **HemoPI2**：500K 抽样（2.5%），97.5% NULL。
- **MHCflurry**：135K（5–15 aa 长度限制），99.3% NULL。
- **anoxpepred-frs / -chelating**：通过 `scripts/derive_anoxpepred_branches.sql` 脚本从 `anoxpepred.details->>'frs_score'` / `'chel_score'` 派生为全 20.25M 列（提案 §0 没料到这一步已被做过，结果是更好：覆盖比预期高）。

### 2.2 与提案不符（2 项缺失）

**`netmhcipan_pctrank`**：

- 提案 §0 声称 14.8M 覆盖（10–30 aa）。
- DB 实际 tool 名 `netmhcipan_pctrank` / `netmhciipan` / `mhc-ii` / `netmhc-ii` 全部查询无返回。
- 结论：**该分数根本没跑过**，要么是 job 没启动，要么是 tool 名拼写不一样、需进一步排查。
- 在管线里**降级为软信号**：列全 NULL → 不参与硬门控 → 前端"未评估"标记永久生效。

**`bepipred`**：

- 提案 §0 声称 full 覆盖。
- DB 实际 `bepipred` / `bepipred3` / `bepipred-3.0` / `bcell-epitope` 全部查询无返回。
- 结论：**该分数也没跑过**。
- 在管线里**分量自动归零**：Winsorized std = 0 → 权重 = 0；不参与综合分计算。

## 3. 关键生物学影响

### 3.1 免疫原性评估**只能看 MHC-I，不能看 MHC-II**

MHCflurry 只覆盖 0.7% 肽（5–15 aa），且 NetMHCIIpan 缺失。意味着：

- 长肽（>15 aa）的免疫原性评估**当前不可用**。
- 对注射递送场景（README §二："注射免疫暴露是首要风险"），免疫收紧到 0.35 的硬门控**只对短肽生效**——长肽几乎全部"免疫未评估"。

**这是本方向当前最大的安全缺口**。建议在补算前对所有注射候选加注"免疫风险未评估，需湿实验验证"。

### 3.2 B 细胞表位缺失 = 抗体识别能力未评估

bepipred 缺失意味着候选肽的抗体结合能力没人评过。对**外用涂抹 / 伤口敷料**场景（候选蛋白直接接触体液），这是个潜在问题——但因为算法不存在，**当前管线无法补救**。

### 3.3 致敏性 / 穿膜性 / 聚集倾向都有数据

algpred2 + plm4cpps + 一维 aggrescan_a3v 这三项是软信号，但都有真实数据可用，所以"安全·致敏"、"可开发性·穿膜"、"可开发性·聚集"三件事能评。

## 5. 补算建议（优先级排序）

| 优先级 | 工具 | 缺失影响 | 建议 |
|---|---|---|---|
| 高 | `netmhcipan_pctrank` | 注射免疫评估失效 | 尽快补跑（model 接受 10–30 aa，覆盖完整） |
| 高 | `bepipred` | B 细胞表位评估失效 | 尽快补跑（BepiPred-3.0 输入长度 1–50，覆盖完整） |
| 中 | `hemopi2` | 97.5% 肽溶血风险未评估 | 模型支持任意长度，但跑全库 20M 任务量大，可分批 |
| 低 | `mhcflurry` | 受长度限制无法补全 | 物理上无法补，保留为 5–15 aa 子集参考 |

**经验估算**：

- NetMHCIIpan 全 20M 跑分：模型 ~10 peptides/sec/machine，16 核约 14 天（与 ToxinPred3 同量级瓶颈）。
- BepiPred-3.0：ESM2 backbone，单条推理 ~0.5s，全 20M 约 12 天。
