## 1. 我们要解决的问题

### 1.1 生物学问题

蚕丝 / 蜘蛛丝蛋白是结构材料、没有功能活性。如果把一段有抗氧化活性的短肽嵌入丝蛋白骨架，就能得到兼具结构支撑 + 抗氧化功能的融合蛋白——可用于伤口敷料、组织工程、抗氧化涂层等场景。

自然界和宏基因组里有海量短肽，绝大多数有毒、有溶血性、有免疫原性。**直接挑活性最强的肽会带来致命风险**，必须做安全门控。

### 1.2 任务的数学本质

在 2,025 万条短肽组成的巨大搜索空间里，做**强约束多目标筛选**：
- 安全维度（毒性 / 溶血 / 免疫原性）—— 一票否决
- 功能维度（抗氧化活性）—— 决定通道
- 可开发性维度（穿膜 / 致敏 / B 细胞表位 / 聚集）—— 综合排名

### 1.3 三条不可妥协的原则（来自提案）

1. **安全一票否决**：毒性 / 溶血 / 免疫任一项不达标就淘汰，不能靠加权平均补偿——湿实验里一票否决的失败就是失败。
2. **每个指标只用一次**：功能分只在最初选通道用一次，确定"高活性 vs 低活性"通道后，排名就不再参考它，避免功能分喧宾夺主。
3. **权重由数据自己决定**：唯一允许加权的那一轮，权重用指标的 Winsorized 标准差反推——区分度高的自动升权、低的自动降权，仅保留一个人工干预系数 α（默认 1.0）。

## 2. 筛选流程的四轮漏斗

```
2,025 万肽
  │
  │  Round 1: 功能预筛（aopxsvm P90+）
  │  → 2,024,889 条（top 10%）
  ▼
2,024,889 条高活性候选
  │
  │  Round 2: 安全一票否决（3 项）
  │  → 173 条通过（top 通道 113 + bottom 通道 60）
  ▼
170 条安全肽（含对照 57）
  │
  │  Round 3: 加权综合分（4 种递送 × 4 个分量）
  │  → 4 套 composite_* 分
  ▼
170 条 construct 落库
```

### Round 1 · 功能预筛

- 用 **AOPxSVM**（抗氧化活性预测专用 SVM）打分。
- AOPxSVM 在 20M 库上有 72.83% 判为阳性，0.5 阈值失真——所以**用全库分位**（P90）作 cutoff，而不是固定 0.5。
- 取 P90 以上：**2,024,889 条**进入下一轮。

### Round 2 · 安全一票否决（三项独立）

每一项的规则都是"分数存在且超标 → 淘汰；分数缺失 → 放行（但标"未评估"）"——这是**可空缺性原则**。

| 指标 | 阈值 | 覆盖 | 失败效果 |
|---|---|---|---|
| **ToxinPred3**（毒性） | `< 0.38` 通过 | 全 20.25M | 真硬门控；本库覆盖 100% |
| **HemoPI2**（溶血） | `< 0.55` 通过 | 仅 500K 抽样（2.5%） | 软信号；97.5% 肽"未评估" |
| **MHCflurry**（MHC-I 结合） | `< 0.50` 通过；注射 `< 0.35` | 仅 5–15 aa（0.7%） | 软信号；99.3% 肽"未评估" |

对 250 个最终候选，安全门控淘汰率约 30%（Top 24.7%、Bottom 43%）。Bottom 通道剔除率更高——**功能差 + 安全也差的对照肽更没研究价值**。

### Round 3 · 加权综合分（4 种递送 × 4 个分量）

**4 个分量**（越高越好，已归一化到 [0, 1]）：

| 分量 | 来源 | 方向 | 说明 |
|---|---|---|---|
| `cpp` | pLM4CPPs | 高=穿膜强 | 可开发性·穿膜 |
| `sens` | AlgPred2 | 低=致敏 → 取反 | 安全·致敏 |
| `epitope` | BepiPred-3.0 | 低=表位少 → 取反 | 安全·B 细胞表位 |
| `agg` | 一维 AGGRESCAN | 高=促聚集 → 取反 | 可开发性·聚集 |

**权重自动计算**（Winsorized std）：

| 分量 | 区分度 | 归一化权重 |
|---|---|---|
| cpp | 0.236 | 0.312 |
| sens | 0.227 | 0.300 |
| epitope | **0** | **0** |
| agg | 0.292 | 0.387 |

`epitope = 0` 是因为 BepiPred-3.0 在数据库里**没有任何行**——权重自然归零，符合"数据驱动权重"原则。

**4 种递送的权重乘数**：

| 递送 | cpp | sol | thermal | immuno |
|---|---|---|---|---|
| **外用涂抹** (topical) | 1.4 | 1.3 | 0.7 | normal |
| **纳米载体** (nano) | 0.7 | 1.4 | 1.0 | normal |
| **微针** (microneedle) | 1.0 | 1.4 | 1.4 | normal |
| **注射** (injection) | 1.0 | 1.0 | 1.0 | **tight (0.35)** |

**注射的免疫收紧**：对 `mhcflurry ≥ 0.35` 的肽，注射下直接判 failed_safety（综合分置 0、不参与排名）。其余递送按软标记处理。

## 5. 生物学层面的几个注意点

### 5.1 抗氧化的两条机制（FRS + 螯合）

`AnOxPePred` 实际输出两个分：
- **FRS（自由基清除）**：肽直接与自由基反应的能力
- **Chelating（金属螯合）**：肽结合 Fe²⁺/Cu⁺ 等金属、阻止 Fenton 反应的能力

本管线把 anoxpepred-frs 设为"加分项"（≥ 0.5 标记 +1）——只在 500K 抽样里有值的少数肽触发。这是抗氧化机制上的"额外确认"，**不影响主排序**（主排序只看 aopxsvm）。

### 5.2 注射场景下免疫评估的盲区

README §二："注射免疫暴露是首要风险"——但本管线对长肽（>15 aa）**完全没有 MHC-I 评估**，**完全没有任何 MHC-II 评估**。因此：

- 注射候选肽里，**长肽的免疫原性几乎都是"未评估"**。
- 建议对所有注射候选加注"免疫风险未评估，需湿实验验证"。

### 5.3 软信号 = 不确定性，不是"通过"

HemoPI2 / MHCflurry / AlgPred2 / BepiPred / 一维 AGGRESCAN 这些都是**软信号**——意思是"分数存在且超标才标记风险"，**分数缺失 ≠ 通过安全检查**。前端在 Library 页面要展示"已评估 / 未评估"标签，让研究者自己判断风险。

### 5.4 9 个分数的权重差异化

Winsorized std 权重自动让 `bepipred` 因数据缺失而**权重归零**——这意味着 B 细胞表位在当前综合分里完全没贡献。**这条肽抗体识别能力没人评过**——下游湿实验需要单独测 ELISA 或类似实验。

## 6. 已知限制与建议

### 6.1 限制清单

| # | 限制 | 影响 |
|---|---|---|
| 1 | MHC-II 分数（netmhcipan_pctrank）缺失 | 长肽免疫评估失效；注射场景尤其受影响 |
| 2 | B 细胞表位分数（bepipred）缺失 | 抗体识别能力未评估；权重自动归零 |
| 3 | hemopi2 仅 500K 抽样 | 97.5% 肽溶血风险未评估 |
| 4 | MHCflurry 仅 5–15 aa | 99.3% 肽 MHC-I 结合未评估 |
| 5 | Top/Bottom 没填满 150/100 | 30% 被安全门控剔除——这是正确的，但若产品要 250 条，需把候选池从 P90 放宽到 P85 |
| 6 | 一维 AGGRESCAN 是聚集代理 | 不能替代三维结构评估（TemStaPro / SoDoPe）—— 三维在 MVP 范围外 |
| 7 | ToxinPred3 跑分瓶颈 | 24 小时单核，瓶颈在第一阶段就出现，2026 第二阶段通过调度缓解 |

### 6.2 补算建议（按优先级）

1. **高优**：补跑 netmhcipan_pctrank 全 20M —— 长肽免疫评估的核心数据
2. **高优**：补跑 bepipred 全 20M —— B 细胞表位评估
3. **中优**：补跑 hemopi2 全 20M —— 溶血风险完整覆盖；目前 97.5% 缺失
4. **低优**：MHCflurry 受长度限制无法补全，保留为短肽子集参考

### 6.3 湿实验建议

- 170 条候选全部进入湿实验前，**优先做体外溶血实验**（MTT / 红细胞溶血）补 HemoPI2 缺失
- 对注射场景的 Top 候选，**优先做 T 细胞增殖实验** 补 MHC-II 缺失
- 对外用场景的 Top 候选，**优先做皮肤致敏实验**（LLNA） 补 AlgPred2 的真实性
- 候选的多肽序列多样性、来源物种分布等可由前端 Library 页面展示

## 8. 汇报时建议强调的 3 件事

1. **170 条候选已落库、可立即用于湿实验**。Top/Bottom 拉开清晰（aopxsvm 1.0 vs 0.996），综合分排序合理。
2. **当前最大安全盲区是免疫评估**：MHC-II 完全缺失 + MHC-I 受长度限制。注射场景的免疫收紧**只对短肽生效**。建议长肽注射候选**必须**做湿实验免疫验证。
3. **数据驱动权重验证了 README 三原则**：`bepipred` 因数据缺失而权重自动归零——这是工程工程化"铁律"的最好证据；唯一人工干预只剩 α。
